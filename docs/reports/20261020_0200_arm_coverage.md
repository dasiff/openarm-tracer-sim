## 3. Coverage in the search score and the finder ranking (done, design plan §3.4)
- Search key = smallest margin capped at 0.3, + 2 % of the mean margin, - 3 x arm coverage (a fraction of the image); so once the margins are comfortable it prefers less coverage (the variant search used it).
- Finder ranking: requirements, then the widest pedestal range, then **smaller arm coverage**, then the larger tolerance. Caveat: the width is compared exactly (in 1 cm steps) and widths almost never tie (5 passing candidates, widths 5, 3, 3, 1, 0 steps for the variant), so in practice coverage and tolerance only decide a tie. If you want coverage to matter more, I can treat ranges within 2 cm of the widest as equal and then rank by coverage.
