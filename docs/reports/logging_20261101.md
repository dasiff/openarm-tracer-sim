## Logged Columns (99 total)

### Phase 1: Existing Baseline
- `tick`, `t_sim`: frame counter and simulation time
- `phase`, `phase_i`: current phase name and index

### Phase 2: Joint State
- `q_L/R_1..7`, `qd_L/R_1..7`: measured joint angles and velocities (14 joints)

### Phase 3: Servo Control (Session 2) 
- `tau_cmd_L/R_1..7`: raw joint targets (position actuator commands, before gravity offset)
- `tau_ff_L/R_1..7`: gravity feedforward offset (added to command, clipped to joint range)

### Phase 4: Sag Correction (Session 4)
- `sag_p_L1..L3`: sag correction position error integral [m] (first 3 dims of C["p"])
- `sag_r_L1..L3`: sag correction rotation error integral [rad] (first 3 dims of C["r"])

### Phase 5: Ramp & Blend (Session 4)
- `ramp_k`: phase-start ramp parameter (S["ramp_k"], accumulates each tick)
- `blend_v_L1..L7`: velocity blend command (S["blend_v"], 7 joint velocities)

### Phase 6: Held Object (Sessions 2-3)
- `held_mass_L`, `held_mass_R`: held-object mass (from HELD_MASS dict, set during PICK)

### Phase 7: IK Solver Diagnostics (Session 1)
- `va_L1..L7`: IK solver actual velocity [rad/s]
- `vr_L1..L7`: IK solver requested velocity (without speed limit)
- `vel_bind`: bitmask (1 per joint) showing which joints hit speed limit
- `n_vel_bind`: count of joints hitting speed limit
- `slack_min`: minimum slack to joint limits [rad]
- `n_coll`: number of active collision avoidance limits
- `n_vel_limit_obj`: number of velocity limit objects in IK constraints

## Implementation Notes

### Design Decisions

1. **Module-Level Logging Dicts:** 
   - SERVO_LOG in control_loop.py, GRAVITY_LOG in gravity_ff.py
   - Simple, non-intrusive, read via module introspection
   - Avoids architecture changes to closures or function signatures

2. **Per-Tick Capture:**
   - One value per tick (150 Hz control rate)
   - Captured BEFORE physics steps (one tau_ff value used for all 5 physics steps)
   - tau_cmd from first physics step of tick (ramp block[0])

3. **Closure Extraction:**
   - gc.get_objects() finds step_inner() at runtime (reads-only, no modification)
   - Extracts dict from __closure__ attribute of function object
   - Logging-only: even if extraction fails, computation proceeds unchanged

4. **Extraction Script Pattern:**
   - Modeled on run_measstart_inject.py (proven, tested approach)
   - Wraps functions (mink.solve_ik, MinkArm.step) for IK logging
   - Runs same demo_video.py command, adds per-tick CSV capture

### RULE 1 Compliance

✅ **No computation changes:**
- All added code is logging-only (reads state, does not modify it)
- SERVO_LOG, GRAVITY_LOG are passive observations
- Try/except silently skips if extraction not active
- No changes to: gains (gff.kp, sag control gains), limits, ramp time, order of operations

✅ **No config changes:**
- No entries added to task_config.py
- All logging controlled by presence of extraction script (non-persistent)

✅ **No random seed changes:**
- Logging reads from existing computations
- No new random sampling or stochastic operations
